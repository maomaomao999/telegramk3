## English (U.S.)

### Name

Kislap

### Subtitle

Connect on Your Terms

### Promotional text

Batch-forward with a review step, preview conversations privately, control activity signals, and meet nearby learning partners.

### What's New

Kislap 1.2 introduces a new Home built around intentional communication:

- Batch Forward with pre-send review, live progress, pending-task cancellation and destination results
- Peek Mode for opening conversations without automatic read advancement
- Timed Stealth sessions that pause typing and recording activity signals from this client
- Nearby Learning with approximate distance and time-limited visibility

Messaging, groups, voice calls and video calls remain available from the Communication section.

### Description

Kislap helps you communicate intentionally and find people to learn with.

YOUR KISLAP HOME

Start from a Kislap-owned Home where privacy tools, batch actions and nearby learning are organized separately from everyday chats and calls.

BATCH FORWARD WITH CONTROL

Select multiple messages and destinations, review the batch before sending, follow every destination's progress, and cancel items that are still pending. Existing content restrictions, destination permissions and rate limits continue to apply.

PEEK MODE

Open conversations without automatically advancing their read state from this client. Manual Mark as Read remains available whenever you choose it.

TIMED STEALTH

Pause typing, sticker-selection, voice-recording and instant-video activity signals from this client for one hour, eight hours or until you turn the mode off.

NEARBY LEARNING

Discover nearby partners for English practice, programming, singing and other skills. Kislap uses approximate distance ranges, user-controlled visibility and automatic expiry instead of displaying an exact position.

KEEP THE CONVERSATION GOING

Messages, groups, media, voice calls and video calls support ongoing learning relationships.

SAFETY AND CHOICE

- Approximate area instead of an exact position
- Time-limited Nearby visibility
- Report and Block controls
- Dating is separate, optional and off by default
- Clear controls for Peek and Stealth modes

Kislap combines learning discovery, deliberate sharing and familiar communication in one focused experience.

## Simplified Chinese

### Name

Kislap

### Subtitle

按你的方式连接

### Promotional text

批量转发前统一复核，私密预览会话，自主控制活动状态，并发现附近的学习搭子。

### What's New

Kislap 1.2 带来全新的自主连接首页：

- 批量转发支持发送前复核、实时进度、取消待发送任务和逐目标结果
- 隐私预览模式可在打开会话时暂停自动推进已读状态
- 潜水模式可按一小时、八小时或持续开启，暂停本客户端的输入和录制活动广播
- 附近学习继续使用模糊距离与限时可见

消息、群组、语音通话和视频通话仍可从“通信”区域进入。

### Description

Kislap 帮你更自主地沟通，也帮你找到一起学习的人。

KISLAP 首页

登录后直接进入 Kislap 自有首页。隐私工具、批量操作、附近学习与日常消息和通话分区呈现。

可控的批量转发

选择多条消息和多个目标，发送前统一复核，查看每个目标的实时进度，并取消仍在等待发送的任务。内容保护、目标权限和频率限制继续生效。

隐私预览

从本客户端打开会话时暂停自动推进已读状态；需要时仍可手动标记为已读。

定时潜水

暂停本客户端的输入、选贴纸、语音录制和即时视频活动广播，可选择一小时、八小时或持续开启。

附近学习

寻找英语口语、编程、唱歌和其他技能的学习搭子。Kislap 显示模糊距离范围，并由用户主动开启限时可见，不展示精确位置。

持续沟通

消息、群组、媒体、语音通话和视频通话帮助学习关系持续发展。

安全与选择

- 使用模糊区域，不展示精确位置
- 附近可见会自动到期
- 举报与屏蔽入口
- Dating 独立、自愿加入且默认关闭
- 隐私预览和潜水模式状态清晰可见

Kislap 将学习发现、自主分享和熟悉的通信能力整合为一个聚焦的体验。
